# 🎵 Sistema Musical

## 📌 Sobre o Projeto

O **Sistema Musical** é um projeto desenvolvido para organizar e gerenciar informações sobre artistas e músicas. A plataforma possui uma interface simples e intuitiva, permitindo que o usuário navegue entre as diferentes páginas e visualize uma biblioteca musical.

O sistema foi desenvolvido como atividade prática, com o objetivo de aplicar conhecimentos de desenvolvimento web, utilizando HTML, CSS, PHP e MySQL.

## 🎯 Objetivo

O principal objetivo do projeto é desenvolver um sistema de gerenciamento musical que permita organizar artistas, cadastrar músicas e consultar informações de uma biblioteca musical.

Além disso, o projeto busca aprimorar os conhecimentos em programação, criação de páginas web, integração com banco de dados e desenvolvimento de sistemas.

## ✨ Funcionalidades do Sistema

O sistema apresenta diferentes funcionalidades para facilitar a organização das informações musicais:

- **Login:** página de acesso ao sistema por meio de usuário e senha.
- **Menu Principal:** apresenta as opções disponíveis para navegação.
- **Cadastro de Artistas:** formulário para inserir informações dos artistas, como nome, gênero musical, país e foto.
- **Cadastro de Músicas:** permite informar o título da música, artista, álbum, gênero musical, link do YouTube, capa do álbum e letra.
- **Biblioteca Musical:** página destinada à visualização das músicas cadastradas.
- **Filtros de Pesquisa:** campos para pesquisar músicas por título, álbum, artista ou gênero.
- **Gerenciamento:** interface com opções de edição e exclusão de registros.

## 🖥️ Páginas do Projeto

### 1. Login
Página inicial de autenticação do usuário, com campos para informar nome de usuário e senha.

### 2. Menu Principal
Apresenta as principais opções do sistema:
- Gerenciar artistas.
- Cadastrar músicas.
- Acessar a biblioteca musical.

### 3. Cadastro de Artistas
Permite preencher informações importantes sobre os artistas, incluindo nome, gênero musical, país de origem e imagem.

### 4. Cadastro de Músicas
Possibilita registrar informações das músicas, relacionando cada uma a um artista e adicionando detalhes como álbum, gênero, link do YouTube e letra.

### 5. Biblioteca Musical
Reúne as músicas em uma tabela organizada, exibindo informações como título, artista, álbum, gênero e acesso ao YouTube.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** utilizado para estruturar as páginas e os formulários.
- **CSS3:** responsável pela aparência visual, cores, organização e estilização dos elementos.
- **PHP:** utilizado para desenvolver a parte lógica e permitir a integração com o banco de dados.
- **MySQL:** sistema de gerenciamento de banco de dados utilizado para armazenar as informações.
- **Visual Studio Code:** editor utilizado para desenvolver e organizar os arquivos do projeto.

## 📁 Organização dos Arquivos

- `index.html` – página do menu principal.
- `login.html` – página de autenticação.
- `cadastro_artista.html` – formulário de cadastro de artistas.
- `cadastro_musica.html` – formulário de cadastro de músicas.
- `listagem_musicas.html` – página da biblioteca musical.
- `styles.css` – arquivo responsável pela estilização.
- `conexao.php` – arquivo destinado à conexão com o banco de dados.
- `geraSenha.php` – arquivo relacionado à geração de senha.
- `logout.php` – arquivo destinado ao encerramento da sessão.
- `valida.sessao.php` – arquivo destinado à validação da sessão.
- `bd.sql` – arquivo destinado à estrutura do banco de dados.
- `img - Ref/` – pasta que contém imagens utilizadas como referências visuais de artistas e músicas.

## 🎨 Identidade Visual

O projeto utiliza elementos visuais relacionados ao universo musical, como ícones, imagens de artistas, capas de álbuns e botões de navegação.

A interface foi organizada para proporcionar uma experiência simples e agradável, facilitando o acesso às funcionalidades disponíveis.
